# הכנה להגנה — ShowShelf

זהו מדריך לתרגול, לא אישור שכבר הבנת או בדקת את הקוד.

## הצגה קצרה
ShowShelf היא אפליקציית React שמציגה סדרות מ־TVmaze. יש רשימה עם חיפוש וסינון, פרטי סדרה, מועדפים שנשמרים בדפדפן והשוואת שתי סדרות. אין שרת או בסיס נתונים משלנו.

## מסלול תרגול של כשבע דקות
1. הראה את ארבעת העמודים, חפש סדרה ושמור מועדף.
2. פתח App.tsx: הראה את Routes ואת state המועדפים.
3. פתח BrowsePage.tsx: הראה useEffect, fetch, מצבי טעינה ושגיאה ואת map.
4. פתח ShowCard.tsx: הסבר את props ואת Link לפרטים.
5. פתח ShowDetailsPage.tsx: הסבר איך useParams קורא את המזהה מהכתובת.
6. פתח filterShows.test.ts והסבר קלט, פעולה ותוצאה צפויה של בדיקה אחת.
7. הראה את PROMPTS.md ואת ה־commits ותאר בכנות את תהליך העבודה.

## שאלות לתרגול ותשובות מנחות
- למה favorites נמצא ב־App? כי כמה עמודים צריכים את אותו מידע. מעבירים אותו ואת הפעולה שמשנה אותו באמצעות props.
- מה ההבדל בין state ל־props? state הוא מידע שרכיב מנהל ויכול לעדכן; props הוא מידע שהרכיב מקבל מההורה.
- מה גורם לרשימה להשתנות בזמן הקלדה? setQuery משנה state, React מרנדר שוב, והסינון מחושב מחדש. אין בקשת רשת בכל הקלדה.
- למה key הוא id ולא שם הסדרה? המזהה ייחודי ויציב גם אם שם או מיקום משתנים.
- מה עושה useEffect? מפעיל בקשת נתונים לאחר שהעמוד מופיע, ומנקה אותה כשהעמוד נסגר או התלויות משתנות.
- למה צריך AbortController? כדי לבטל בקשה שכבר אינה רלוונטית אחרי מעבר עמוד.
- מה קורה ב־/shows/2? הנתב בוחר את עמוד הפרטים; useParams מחזיר את הטקסט 2; העמוד מבקש את הסדרה עם המזהה הזה.
- למה בודקים null במפורש בדירוג? אפס הוא ערך מספרי תקין, בעוד null אומר שאין מידע.
- איך המועדפים נשארים אחרי רענון? כותבים JSON ל־localStorage וקוראים ומאמתים אותו כשהאפליקציה עולה.
- מה הבדיקות מוכיחות? את הלוגיקה וההתנהגות במקרים מוגדרים. בדיקות עם fetch מדומה לא מוכיחות שה־API החיצוני זמין תמיד.
- למה יש רק חלק מהסדרות? בחרנו דף ראשון אחד מה־API כדי לשמור על היקף פשוט. המגבלה מוצגת בממשק.

## תרגילים שאתה צריך לעשות בעצמך
- שנה את כותרת Browse ומצא את הקובץ הרלוונטי בלי חיפוש של הסוכן.
- הסבר בדיקת שילוב שם וז׳אנר לפני הרצתה.
- מצא איפה תוסיף שדה נוסף להשוואה: הכותרות בעמוד Compare והערכים ב־getComparisonFacts.
- שמור והסר מועדף, רענן והסבר את מסלול המידע.
- כתוב הערה אמיתית על מה בדקת ומה שינית, כפי שהמרצה ביקש.

בהגנה עצמה עונים לבד, בלי סוכן ובלי חיפוש. אין לשנן תשובה בלי לזהות את הקוד שאליו היא מתייחסת.
